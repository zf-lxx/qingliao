# 自写服务端补齐计划

对照 `app/`（mithka 系客户端）和 `server/`。客户端大约 460 个 TD 风格方法，适配层只接了一部分，其余是 `QL_UNSUPPORTED`。这里只列轻聊自己要用的缺口，不含 Stars、礼物、Premium、商业账号、护照。

## 这一轮（本分支已实现，客户端适配已接上）

- 删会话：私聊对自己移除；群/频道群主可对所有成员删除。群主仍有其他成员时不能把群留成无主。
- 私聊删掉后再次发起会加回成员，历史停在删除时的序号。
- 个人简介、用户名（`PATCH /v1/me` 的 `bio` / `username`）。
- 群简介、慢速模式（非管理员发送间隔）。
- 聊天背景和默认背景（`/v1/me/wallpapers`），重启后由服务端带回。
- 群邀请链接：创建、修改、撤销、查看、加入。
- 按名字搜群成员。
- 按发送者清空消息（管理员，或删自己的）。
- 投票加选项（发起人，未关闭，最多 10 项）。

## 下一轮（客户端有入口，但不靠外部服务）

- 群权限逐项生效（现在只存展示，发送侧只落实了慢速模式和已有的禁言/新成员限制）。
- 转让群主、按条件升级超级群。
- 位置、名片、骰子、视频便笺、定时发送、阅后即焚。
- 自定义 emoji 资源；`.tgs` / `.webm` 动态贴纸。
- 送达回执（现在只有已读）。
- 新成员是否能看加入前的历史，做成群设置而不是写死。
- 媒体孤儿清理、OG 预览图片代理。
- Bot `sendAnimation` / `sendVideoNote`。

## 需要外部条件，先不做

- 小米推送 / FCM 真机：代码在，缺开发者凭据和锁屏验收。
- 换手机号、短信验证码、通行密钥、恢复邮箱。
- R2/S3 与预签名上传。
- 语音转文字、服务端转码。
- 一对一通话、群通话、直播动态、端到端加密。
- 多实例共享一个 SQLite。
