# 自写服务端补齐计划

对照 `app/`（mithka 系客户端）和 `server/`。客户端大约 460 个 TD 风格方法，适配层只接了一部分，其余是 `QL_UNSUPPORTED`。这里只列轻聊自己要用的缺口，不含 Stars、礼物、Premium、商业账号、护照。

## 这一轮（本分支已实现，客户端适配已接上）

- 删会话：私聊对自己移除；群/频道群主可对所有成员删除。群主仍有其他成员时不能把群留成无主。
- 私聊删掉后再次发起会加回成员，历史停在删除时的序号。
- 个人简介、用户名（`PATCH /v1/me` 的 `bio` / `username`）。
- 群简介、慢速模式（非管理员发送间隔）。
- 聊天背景和默认背景（`/v1/me/wallpapers`），重启后由服务端带回。
- 群邀请链接：创建、修改、撤销、查看、加入。
- 按名字搜群成员。
- 按发送者清空消息（管理员，或删自己的）。
- 投票加选项（发起人，未关闭，最多 10 项）。

## 下一轮（本分支已实现）

- 群权限逐项生效：缺省允许，管理员不受限。发送、置顶、邀请按 `can_send_*` / `can_pin_messages` / `can_invite_users` 判断。
- 转让群主要校验当前密码。群主可以把至少两人的普通群升成超级群，会话 id 不变，成员仍可发言。
- 位置、地点、名片、骰子、视频便笺、动图。骰子点数由服务端掷出。
- 定时发送先入队，到点或对方在线后再写入历史。阅后即焚在别人读到后删除；群自动删除时间到期后删除。
- 自定义 emoji 包，以及 `.tgs` / `.webm` 贴纸。
- 送达序号和查看者、已读时间。送达不会当成已读。
- 新成员能不能看加入前的历史，由群设置决定，默认不能。
- 超过一小时且无人引用的媒体会被清掉。链接预览图经服务端代理，内网地址拒绝。
- Bot `sendAnimation` / `sendVideoNote`。

## 再下一轮（本分支已实现）

- 会话列表带回升级、自动删除、新成员历史、公开用户名、禁止转发和入群申请数，重启后超级群不会变回普通群。
- 公开用户名。`https://t.me/名字/序号` 和 `mk://msg` 可以复制、点开消息。
- 按日期跳到不晚于该时刻的最后一条消息。
- 非匿名投票可以查看投了某个选项的人。
- 邀请链接和公开用户名可以改成需要管理员同意。同意或拒绝后才入群。
- 群可以禁止转发。替换自己发出的图片、视频或文件。定时消息可以改时间，也可以马上发出。
- 动图、视频便笺和投票可以按类型搜索。

## 需要外部条件，先不做

- 小米推送 / FCM 真机：代码在，缺开发者凭据和锁屏验收。
- 换手机号、短信验证码、通行密钥、恢复邮箱。
- R2/S3 与预签名上传。
- 语音转文字、服务端转码。
- 一对一通话、群通话、直播动态、端到端加密。
- 多实例共享一个 SQLite。
