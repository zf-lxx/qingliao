# 0.2 开发/交付记录

原则：优先点击、返回和弹出微交互，独立 Flutter 重写，不复制 Telegram 源码/素材。完整目标见 tg-style-spec.md；没有真机帧率数据时不宣称120Hz无掉帧。

## 节点1：统一 motion kit
- `client/lib/ui/motion/`：曲线、时长、PressableScale + InkRipple、TgIconButton、TgPageRoute、TgPopup、TgDialog、TgSheet。
- 页面路由替换；旧聊天页单独的返回拖拽移除。对话框/底部弹层统一入口。
- 返回边缘直接跟手，速度/剩余距离决定完成或取消；背景列表有独立视差和遮罩。
- 明确偏差：当前页面使用整屏滑入、背景1/4屏视差与30%遮罩，是轻聊的统一设计参数，不声称对应所有TG的48dp/predictive分支。Android系统预测返回的缩放形变还未完成。
- Ripple 的颜色按轻聊主题透明度处理；TgSheet沿用Flutter可拖拽底层，有TG时长，但尚非所有曲线/弹簧逐像素复刻。

## 节点2：聊天列表
- 大号左标题、圆角搜索、文件夹胶囊/计数，选中背景与短下划线320ms滑动。
- 58dp头像、名称/时间/回执/静音/置顶/@/未读角标；未读计数切换430ms，行重排180ms。
- 左右滑动分别归档/标记未读，调用已有真实会话状态接口；归档入口行。
- 底部悬浮胶囊导航（聊天、缓存联系人、设置、个人资料）；写消息按钮280ms随滚动显隐。联系人可建立真实私聊，账号隐私设置沿用现有页面。
- 空态不虚构联系人；建议卡片、相机小FAB还未实现。
