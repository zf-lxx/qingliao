# 0.2 开发/交付记录

> **说明：** 本文是轻聊立项阶段的设计/手感研究笔记，只作历史参考。产品名称是轻聊，不连接 Telegram 服务器，也不是 Telegram 或 mithka 客户端。文中对 Telegram 等公开实现的引用仅用于说明交互研究，不代表本产品的身份或协议。


原则：优先点击、返回和弹出微交互，独立 Flutter 重写，不复制 Telegram 源码/素材。完整目标见 tg-style-spec.md；没有真机帧率数据时不宣称120Hz无掉帧。

## 节点1：统一 motion kit
- `client/lib/ui/motion/`：曲线、时长、PressableScale + InkRipple、TgIconButton、TgPageRoute、TgPopup、TgDialog、TgSheet。
- 页面路由替换；旧聊天页单独的返回拖拽移除。对话框/底部弹层统一入口。
- 返回边缘直接跟手，速度/剩余距离决定完成或取消；背景列表有独立视差和遮罩。
- 明确偏差：当前页面使用整屏滑入、背景1/4屏视差与30%遮罩，是轻聊的统一设计参数，不声称对应所有TG的48dp/predictive分支。Android系统预测返回的缩放形变还未完成。
- Ripple 的颜色按轻聊主题透明度处理；TgSheet沿用Flutter可拖拽底层，有TG时长，但尚非所有曲线/弹簧逐像素复刻。

## 节点2：聊天列表
- 大号左标题、圆角搜索、文件夹胶囊/计数，选中背景与短下划线320ms滑动。
- 58dp头像、名称/时间/回执/静音/置顶/@/未读角标；未读计数切换430ms，行重排180ms。
- 左右滑动分别归档/标记未读，调用已有真实会话状态接口；归档入口行。
- 底部悬浮胶囊导航（聊天、缓存联系人、设置、个人资料）；写消息按钮280ms随滚动显隐。联系人可建立真实私聊，账号隐私设置沿用现有页面。
- 空态不虚构联系人；建议卡片、相机小FAB还未实现。

## 节点3：聊天视觉与基本多选/资料
- 悬浮模糊头部胶囊+独立圆菜单，原创程序生成低对比图案墙纸（独立RepaintBoundary）；分组消息、尾巴、气泡内时间/回执。
- typing三点320+320ms变化、150ms错开；浮动输入支持表情/图片附件，camera↔send 220ms QuINT替换（未开放mic录音），消息250ms入场；pending自有消息有92dp/20dp上移入场，**不是完整匹配输入框形状的MessageEnterTransition**。
- 长按消息的模糊/暗化背景+reaction栏/菜单，150+16×itemCount展开、150ms关闭；顶部⋮从右上角缩放淡入；静音子菜单和本机消息搜索有真实行为。
- 多选：200ms行右移35dp、绿色复选圆圈与整行高亮，头部计数切换，回复/复制/单条自有编辑/权限校验后的多条撤回；返回先退出多选。转发、拖选、反应爆发动画未实现。
- 资料页180ms/Decelerate导航与头像Hero，110dp圆头像、信息卡、真实静音动作；媒体/链接吸顶tabs、三列图片网格和查看。**只统计已加载消息**，无全量媒体API、快滚/月桶/2–6列捏合、全幅头像展开、QR或分享入口。
- 共用token和TgGlass（半透明blur）；旧设置/个人账号页面只统一了Theme，尚未全部重绘成最终TG布局；浅色主题待做。
