# 轻聊路线图

> **说明：** 本文是轻聊立项阶段的设计/手感研究笔记，只作历史参考。产品名称是轻聊，不连接 Telegram 服务器，也不是 Telegram 或 mithka 客户端。文中对 Telegram 等公开实现的引用仅用于说明交互研究，不代表本产品的身份或协议。


## 0.1.0（首版）
文字/富文本收发、断线补发、未读/@/已读/草稿、回复/编辑/撤回/反应/置顶、图片（压缩+鉴权）、邀请注册、后端部署香港。

## 0.1.1（已发布）
- 连接标题状态、应用握手超时/心跳失活检测、网络变化/回前台立即重连
- 真实图片回复的发送者/缩略图/媒体摘要、引用跳转高亮
- 图片 Hero 展开、缩放/拖动关闭、相册保存/系统分享
- 日期胶囊、未读分隔与首次定位、到底部/提及跳转

## 0.2 Telegram 风格重设计 + 媒体消息
**0.2.0 是阶段包，不是整个0.2范围完工。** 已交付与未完成事项分别见 [0.2-status.md](0.2-status.md) 与 [tg-style-spec.md](tg-style-spec.md)。

已完成动效基础、聊天列表、聊天头/输入/原创墙纸/分组尾巴、基础多选和本机媒体资料页。0.2后续补全云端搜索/封锁/举报/清空/媒体索引、完整资料动画，以及下面的媒体消息。

- 语音消息：按住录音、上滑锁定、左滑取消、波形、播放进度、听筒/扬声器切换
- 视频消息：相册选择、客户端压缩、缩略图、内嵌播放
- 文件发送：任意文件、进度、断点下载
- 相册多图分组、查看器左右翻页（单图Hero/缩放/滑动关闭已在0.1.1完成）

## 0.3 推送与常驻
- 小米推送接入（等凭据）、FCM 接入
- 前台服务兜底、通知分组与快捷回复

## 0.4 体验与搜索
- 动态贴纸（Lottie/TGS 风格）、贴纸包
- 中文全文搜索界面：筛选、跳转上下文
- 链接预览卡片、投票

## 0.5 Bot
- 兼容 Telegram Bot API（sendMessage/getUpdates/webhook、inline_keyboard、callback_query）
- 测试接入现有 LLM agent

## 0.6 通话
- 一对一语音/视频通话（WebRTC + coturn）
- 群通话（SFU，如 LiveKit，单独机器）

## 远期
拼音/OCR/语音转文字/语义搜索、端到端加密、媒体迁移 R2。

体积约束：安装包不超过约 50MB，大资源按需下载。
